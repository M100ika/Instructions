2. Заявки — макет рабочего кабинета (ИТС): https://m100ika.github.io/Instructions/python_server/index.html

Вкладка «Заявки» открывается также из окна сотрудников на главной странице.
По умолчанию работает демонстрация на вымышленных данных: выбор вида для инженера
или старшего инженера, поиск, фильтры, карточка заявки, назначение исполнителя
и предпросмотр Telegram. Сообщения в демонстрации не отправляются.
Через «Источник данных» можно подключить существующий Flask-сервер для просмотра
заявок. Реальные назначения, Telegram и авторизация в новом интерфейсе пока не подключены.
Описание возможностей и следующего этапа: [python_server/DISPATCH.md](python_server/DISPATCH.md).
`ets_dispatch.html` перенаправляет на общий интерфейс, чтобы не поддерживать две копии.
